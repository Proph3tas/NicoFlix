# NicoFlix

Lecteur vidéo 4K et vidéothèque personnelle façon Netflix, pour Windows 10 / 11.

## Installer

1. Ouvre la page **[Releases](https://github.com/Proph3tas/NicoFlix/releases/latest)** et télécharge **NicoFlix-Setup.exe**.
2. Lance-le. **Windows affiche un écran bleu « Windows a protégé votre ordinateur »** : c'est normal pour un logiciel gratuit
   non signé par un certificat payant. Clique sur **« Informations complémentaires »** puis sur **« Exécuter quand même »**.
   Tu ne le verras qu'une seule fois : les mises à jour suivantes se font depuis NicoFlix, sans cet écran.
3. Suivant → Installer → Terminer. Aucun droit administrateur n'est nécessaire.
4. Dans NicoFlix : **Réglages → Dossiers → Ajouter un dossier** avec tes films et séries. Les affiches et résumés arrivent tout seuls.

## Mettre à jour

NicoFlix vérifie lui-même les nouvelles versions au démarrage et propose « Mettre à jour maintenant ».
Menu **Aide → Rechercher une mise à jour** pour forcer la vérification.

## Désinstaller

Windows → Paramètres → Applications → NicoFlix → Désinstaller (il propose de garder ou d'effacer ta progression).
